## Overview
This directory contains the theoretical and architectural solutions to all six conceptual scenarios in Section A:
* **Scenario 1 (S1):** Missing Data Strategy & Type Casting in Pandas (`delivery_time_mins` median imputation vs dropping; fixing `customer_rating` string-to-float conversion).
* **Scenario 2 (S2):** NumPy Vectorization & Boolean Indexing (Surge day detection without loops, boolean masks, and SIMD/C-level execution advantages).
* **Scenario 3 (S3):** Exploratory Data Analysis & Visualization Strategy (Bivariate correlation with scatter/regplot; categorical distribution with boxplots).
* **Scenario 4 (S4):** Relational Database Joins & Data Completeness (`LEFT JOIN` necessity for zero-order partners vs `INNER JOIN` data loss; `COALESCE` handling).
* **Scenario 5 (S5):** SQL Window Functions vs Aggregations (`DENSE_RANK()` and `LAG()` with `PARTITION BY` vs `GROUP BY` self-joins).
* **Scenario 6 (S6):** CTEs (`WITH` Clause) vs Deeply Nested Subqueries (Readability, reusability, debuggability trade-offs).
